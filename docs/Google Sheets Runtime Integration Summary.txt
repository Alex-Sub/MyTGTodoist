MyTGTodoist — Google Sheets Runtime Integration Summary
Текущий статус

Google Sheets интеграция работает как отдельный operational UI поверх runtime-системы.

Главный принцип:

Runtime DB = source of truth
Google Sheets = operational/read-review interface

Прямых записей из Sheets в SQLite нет.

Архитектура
Основной flow
runtime DB
  -> google-sync
  -> Google Sheets

Google Sheets edits
  -> reverse review
  -> operator apply by ChangeId
  -> organizer-worker /runtime/command
  -> runtime DB
  -> export back to Sheets
