# MANAGEMENT MODEL
Управленческая модель системы MyTGTodoist.

Система разделяет управление на два уровня:

операционный
управленческий

---

# 1. Операционный уровень
(Operational Layer — слой текущих действий)

Этот уровень отвечает за выполнение задач.

Основные сущности:

Task (задача — действие, которое нужно выполнить)

Subtask (подзадача — часть задачи)

TimeBlock (блок времени — выделенный интервал времени)

---

# Task

Поля:

title — название задачи  
status — состояние задачи  
planned_at — плановая дата  
goal_id — связь с целью

Статусы:

WAITING  
PAUSED  
IN_PROGRESS  
DONE

---

# TimeBlock

TimeBlock — запланированный интервал времени.

Поля:

start_at  
end_at  
duration_minutes

---

# 2. Управленческий уровень
(Management Layer — слой управления результатами)

Этот уровень отвечает за:

контроль сроков  
управление обязательствами  
анализ отклонений

Основные сущности:

Cycle  
Goal  
Nudge

---

# Cycle
(цикл управления)

Cycle — период анализа.

Пример:

месяц  
квартал  
проект

Поля:

name  
start_date  
end_date

---

# Goal
(цель)

Goal — результат, который должен быть достигнут к определённому сроку.

Поля:

title  
success_criteria  
planned_end_date  
status

Статусы:

ACTIVE  
DONE  
DROPPED

---

# История переносов

Каждый перенос срока фиксируется.

reschedule_events

Это позволяет видеть:

сколько раз переносилась цель.

---

# Nudge
(сигнал отклонения)

Nudge — это сигнал системы о проблеме.

Примеры:

goal.overdue  
goal.multiple_reschedules

Система не запрещает действия,
она показывает отклонения.

---

# 3. Связь уровней

Goal
↓
Tasks
↓
TimeBlocks

Цель разбивается на задачи.

Задачи выполняются через блоки времени.

---

# 4. Управленческий принцип

Система не заставляет пользователя.

Она:

делает отклонения видимыми.
